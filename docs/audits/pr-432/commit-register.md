Merge trees were compared with their parents. Every SECURITY DEFINER function in 0193 to 0230 at head was checked for a pinned `search_path`. Diffs of the high-risk commits were read (fix commits named by reviews, gitleaks pins, restore and deploy scripts, test removals). Authorship and trailers were checked against CLAUDE.md §7b.
