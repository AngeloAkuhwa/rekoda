# Context Map

Routing table: which docs, source paths and test suites to load for each
area, so a session reads what it needs and nothing else. Paths verified
against HEAD at creation; if a path is missing, trust the tree and fix this
map in the same PR. Risk guidance is the floor per `AGENTS.md` §4 — the
change itself can raise it.

**Global facts every implementer needs:**

- The authority precedence when documents disagree is `AGENTS.md` §2. The
  product/architecture authority is `docs/REKODA_CANONICAL_SPEC.md`
  ("spec §N" below); implementation scope/state is
  `docs/REKODA_END_TO_END_BUILD_PLAN.md`; decisions are findable by name
  in `docs/REKODA_DECISION_REGISTER.md` (a generated index, not a source).
- The launch is NGN-only (ADR 0033, spec §16/Appendix A): multicurrency/FX
  is dark and no task may surface it.
- Monorepo: `apps/api` (NestJS), `apps/web` (Next.js), `packages/core`
  (pure rules, no IO), `packages/db` (schema + RLS + repos),
  `packages/contracts` (zod borders), `packages/shared` (branded types).
  There is no `services/` directory (ADR 0032 removed the sidecars).
- Unit tests are colocated `*.test.ts`; integration tests are colocated
  `*.integration.test.ts` (run: `pnpm --filter @rekoda/db test:integration`
  then `pnpm --filter @rekoda/api test:integration` — **serially, never
  together**). Playwright e2e: `apps/web/e2e/`.
- Guard scripts CI runs: `scripts/check-boundaries.mjs`,
  `check-node-version.mjs`, `check-ui-copy.mjs`, `check-retired-claims.mjs`,
  `check-openapi.mjs`.
- The api integration suite runs against packages' **built dist** —
  rebuild `@rekoda/db`/`@rekoda/core` after editing them.
