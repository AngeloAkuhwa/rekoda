> in `REKODA_LAUNCH_READINESS.md`, which stays authoritative for what each gap
> is. The 41 rows are an inventory, not a promise of 41 PRs: related rows may
> share a PR. Statuses are never collapsed: **MERGED** is not **DEPLOYED TO
> STAGING**, which is not **STAGING ACCEPTED**, which is not **LIVE PROVIDER
> VERIFIED**. "On staging" means the Deploy staging workflow succeeded for that
> commit or a newer `main` commit. Update this file in the PR that changes a row.

private beta or production; **C** = after launch.
