# Rekoda launch backlog register

> **Operational planning register, not specification.** It tracks the remaining
> engineering slices from the A-to-Z plan (22 Oct 2026) against the gap register
> in `REKODA_LAUNCH_READINESS.md`, which stays authoritative for what each gap
> is. The 41 rows are an inventory, not a promise of 41 PRs: related rows may
> share a PR. Statuses are never collapsed: **MERGED** is not **DEPLOYED TO
> STAGING**, which is not **STAGING ACCEPTED**, which is not **LIVE PROVIDER
> VERIFIED**. Update this file in the PR that changes a row.

Priority: **A** = needed before consolidated staging acceptance; **B** = before
private beta or production; **C** = after launch.

that changes a row; a row says MERGED only once its PR is on `main`.
