## How to read the grades

"100%" means different things at different depths. Each feature gets a grade
on one ladder, and no rung is merged with another.

| Rung   | Meaning                                                                                               |
| ------ | ----------------------------------------------------------------------------------------------------- |
| **E1** | Built in code                                                                                         |
| **E2** | Automated tests pass in CI, run against a local stack and provider doubles                            |
| **E3** | Merged to `main` with no known engineering gap: **engineering-complete**                              |
| **S1** | Deployed to staging                                                                                   |
| **S2** | Staging-accepted by the owner                                                                         |
| **P**  | The real provider has been exercised (Paystack, Meta production, Mono, Resend, Anthropic, OpenAI, R2) |
| **L**  | Production-ready                                                                                      |

**Headline:**

- **No feature is at L.** There is no production host.
- **Only the builds the owner accepted before mid-October are at S2** (for
  example G-77, the public API test, accepted 27 Sep 2026).
- **Everything merged since is at E3 or S1, with acceptance pending.** The
  owner batched acceptance on 19 Oct 2026, and that campaign has not run.
- **Nothing that moves money or sends a message has reached P.** The one
  exception is that the Meta transport has been exercised on staging.

So "100% implemented" below means **E3: engineering-complete**. It does not
mean end-to-end proven.
